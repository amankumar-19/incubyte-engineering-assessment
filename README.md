# ACME Salary Management

Full-stack salary management assessment for ~10,000 employees.

**Stack:** Java 17, Spring Boot 3, Spring Data JPA, H2, Angular 18, TypeScript, JUnit/Mockito, Angular tests, Docker.

Features: dashboard analytics, employee CRUD, server-side pagination/search/filter/sort, validation, deterministic 10,000-row seed, currency-aware salary reporting.

See **docs/RUNNING.md** for exact run steps and **docs/** for requirements, architecture, decisions, AI usage, performance notes and demo script.
