# AI-assisted Development

AI was used for requirements analysis, scaffolding, edge-case identification, candidate tests, documentation and code review.

AI output was treated as a draft. Key human checks included monetary precision, multi-currency correctness, API validation, pagination, deterministic seeding, maintainability and removal of unnecessary architecture.

Example prompts:
- "Review this salary model for monetary and multi-currency correctness."
- "Suggest deterministic tests for employee CRUD and pagination."
- "Identify unnecessary complexity for a 10,000-employee salary application."
- "Identify product assumptions that should be clarified rather than silently implemented."

AI accelerated implementation; product scope and architectural choices remained explicit engineering decisions.
